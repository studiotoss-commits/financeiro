# Manutenção de Sites

Aplicação React + Vite para organizar sites de clientes, contratos, frequências, responsáveis, observações e o histórico de manutenções.

## Executar

Na raiz do monorepositório:

```bash
pnpm dev:manutencao-sites
pnpm build:manutencao-sites
```

Esta primeira versão usa dados locais em memória. Persistência, autenticação e integrações ainda não foram implementadas.
